# Módulo 2: Redes Neuronales Convolucionales (CNN)

### Descripción

Este módulo de la asignatura de **Deep Learning** se centra en las **redes neuronales convolucionales (CNN)**, arquitectura fundamental para el procesamiento de imágenes y otros datos estructurados.

El objetivo principal es que el estudiante comprenda el funcionamiento, componentes y estructura de una CNN, así como conocer las principales arquitecturas actuales.

## Objetivos y competencias

Al finalizar este módulo, se espera que el estudiante pueda:

- Comprender el **funcionamiento, los componentes y la estructura** de una CNN.
    
- Conocer las **principales arquitecturas de CNN**, como ResNet o Inception.
    
- Aplicar los conocimientos adquiridos a ejemplos prácticos de procesamiento de imágenes.
    

---

## Enunciado de la actividad

Durante este módulo se abordarán los siguientes temas:

1. **Introducción y conceptos básicos de las CNN**
    
    - Qué es una CNN y para qué se utiliza.
        
    - Diferencias frente a redes neuronales tradicionales.
        
2. **Componentes y estructura de una CNN**
    
    - Capas convolucionales, capas de pooling, funciones de activación.
        
    - Procesamiento de imágenes y extracción de características.
        
3. **Arquitecturas de CNN**
    
    - ResNet, Inception, y otras arquitecturas relevantes.
        
    - Comparativa y aplicaciones típicas.
