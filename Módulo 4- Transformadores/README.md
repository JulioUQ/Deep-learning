## Competencias y objetivos

Los objetivos de este módulo son:

- Conocer la casuística que llevó a la necesidad de plantear una arquitectura alternativa para tratar las tareas de transformación de secuencia a secuencia.
- Conocer los módulos típicos que integran la arquitectura interna de los modelos basados en transformadores, así como sus distintas variaciones.
- Conocer cómo aplicar estos modelos para la solución de problemas de procesamiento de lenguaje natural.
- Conocer cómo aplicar estos modelos para la solución de problemas de procesamiento de imagen.
- Conocer las posibilidades de estos modelos para la resolución de problemas más complejos que utilicen entradas de distinta naturaleza.

## Enunciado de la actividad

Los transformadores (*transformers*) son una arquitectura de red neuronal diseñada originalmente para la transformación de datos secuencia a secuencia, como alternativa a las redes neuronales recurrentes. Su ámbito de aplicación actual es más general.

Se han convertido en una arquitectura generalista capaz de competir, e incluso superar, a otro tipo de redes especializadas, como las recurrentes y las convolucionales. Su uso actual se extiende al tratamiento de texto, sonido, imagen, aprendizaje por refuerzo, entre otros, así como a aplicaciones con datos de entrada heterogéneos que usan distintas clases de datos de entrada.

En este módulo introduciremos la arquitectura de los transformadores. Iniciaremos el módulo realizando una mirada histórica a la casuística que llevó a la introducción y posterior evolución de los mecanismos de atención hasta llegar a una solución estable basada en los transformadores.

A continuación, estudiaremos los distintos componentes que conforman esta arquitectura, así como las distintas variaciones que pueden existir. Finalmente, veremos algunas de las aplicaciones para estos modelos, empezando por las basadas en procesamiento del lenguaje y por la clasificación de imágenes.
